# Шаблон реферата (Typst)

## Как использовать
1. Создайте свою ветку, например `feat/ivanov-topic-2`.
2. Скопируйте `template.typ` в файл работы, например `referat.typ`.
3. Заполните титульный лист и замените подсказки в квадратных скобках.
4. Основную часть разделите по вопросам семинара.
5. Проверьте источники и соберите PDF.
6. Добавьте исходник `.typ` и итоговый PDF в свою ветку и создайте Pull Request в `main`.

## Компиляция
Нужен установленный Typst CLI:
```bash
typst compile referat.typ referat.pdf
```
Также можно использовать Typst Web App и экспортировать PDF.

## Шрифт
Шаблон использует PT Serif. Если шрифт отсутствует, установите его локально. Файлы шрифтов в репозиторий не добавляйте.

## Проверка перед Pull Request
- [ ] Все поля-подсказки заполнены или удалены.
- [ ] PDF успешно собирается.
- [ ] Содержание соответствует заголовкам.
- [ ] Есть введение, основная часть, заключение и список источников.
- [ ] В репозитории лежат исходник `.typ` и PDF.
